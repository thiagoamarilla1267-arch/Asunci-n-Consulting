Cifrado de datos

Protegé archivos contables antes de almacenarlos o compartirlos.

AES-256-GCM
Esta herramienta realiza cifrado real en el navegador mediante Web Crypto API (AES-GCM de 256 bits). La contraseña no se envía a ningún servidor. Usá una contraseña robusta y guardala en un lugar seguro.
